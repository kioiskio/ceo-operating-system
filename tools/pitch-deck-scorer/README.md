# Pitch Deck Scorer

**Problem:** You've built a pitch deck but don't know if it's investor-ready. Friends say "looks good" — investors say "pass."

**Run:**
```bash
python scorer.py           # Interactive mode: answer Y/N for each criterion
python scorer.py --example # See a sample scoring report
```

**What you get:**
- 10-slide assessment against best practices from Sequoia, YC, and a16z
- Weighted scoring (Problem, Solution, Traction, Financials count 3×)
- Prioritized fix list ordered by impact
- Investor-readiness verdict with overall percentage

**Slides assessed:**
1. Title / One-Liner
2. Problem
3. Solution
4. Market Size
5. Traction
6. Business Model
7. Competition
8. Go-to-Market
9. Team
10. Financials / Ask

**Stage:** Any stage where you're preparing to pitch investors (pre-seed through Series B).
